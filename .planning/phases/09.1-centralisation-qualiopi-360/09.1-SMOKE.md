# Phase 9.1 — Smoke manuel DevTools (Centralisation Qualiopi 360°)

**Pré-requis :**
- `pnpm dev:full` lancé (.next clean auto-clean inclus, worker BullMQ démarré, Redis dispo, Postgres dispo, MinIO dispo)
- Connecté en tant qu'ADMIN dans le tenant Start Academy
- Une `TrainingSession` test seedée avec **≥ 3 participants** (mix : au moins 1 AGEFICE et 2 non-AGEFICE)
- Closure-pack déjà généré au moins 1 fois sur cette session (pour que des `Document.entityType='participant'` et `entityType='product'` existent en BDD)
- Au moins 1 PDF `Document.entityType='product'` (Programme) lié au produit de la session — preuve P0
- Un compte FORMATEUR actif dans le même tenant (pour Flow 8 RBAC)

**Conventions communes :**
- Toutes les URLs commencent par `localhost:3002` (port `dev:full` par défaut).
- Les commandes `grep` dans la console serveur tracent le worker BullMQ (`[closure] job xxx started ...`).
- Page Historique `/app/parametres/historique` accessible ADMIN uniquement pour vérifier AuditLog.

## Flow 1 — Re-gen Convention single synchrone (~30 s)

**Cible CENTRAL-02 (D-02 + Pitfall 1 strict mono)** : la Convention est un doc synchrone (pas BullMQ), elle se re-génère immédiatement.

1. Naviguer `localhost:3002/app/sessions/{sessionId}`
2. Scroller jusqu'à la matrice « Documents participants »
3. Cliquer le bouton `⋮` (lucide MoreVertical) sur la cellule **CONVENTION** d'un participant
4. Cliquer "Re-générer le document" dans le DropdownMenu Radix
5. Observer la pastille passer en **RUNNING bleue** (Loader2 spin) puis revenir en **GENERATED vert** (~30 s max)
6. Cliquer la cellule (pastille verte cliquable)

**Attendu :**
- ✅ Toast vert "Document re-généré" (sonner)
- ✅ Pendant la régen : cellule = pastille bleue + icône Loader2 spinning (state RUNNING)
- ✅ Après régen : pastille emerald-100 + Check icon (state GENERATED)
- ✅ Click cellule : ouverture nouveau onglet sur `/api/documents/{id}` → PDF Convention affiché (D-14 1-clic)
- ✅ Page Historique : nouvelle row `documents.regenerate` avec `entity=Document`, `entityId=participantId`, `actorUserId={admin actuel}`
- ✅ `revalidatePath('/app/sessions/{sessionId}')` invalide le cache RSC → recharger la page montre la nouvelle hash
