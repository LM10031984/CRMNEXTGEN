### 1. [Rule 3 — Parallel commit race condition] Plan 03 agent a inclus mes 8 fichiers timeline dans son commit `5017bb6`

- **Trouvé pendant :** Task 2 (commit attempt 1).
- **Symptôme :** `git commit` pour Task 2 a renvoyé "no changes added to commit". `git log -1` montrait commit `5017bb6` "feat(09.1-03): useLocalStorageState + ParticipantDocMatrix..." contenant *aussi* mes 8 fichiers `apprenants/timeline/*`.

- **Impact :** Les fichiers SONT sur disque, tracked par git, fonctionnels. Seul l'attribution du commit est erronée (commit message dit 09.1-03 alors qu'il livre aussi 09.1-04 Task 2).
- **Fix appliqué :** Détection par `git log -1 --stat` → constat fichiers présents. Aucune action corrective (les fichiers fonctionnent ; rebase serait destructif et inutile).
- **Documentation :** ce paragraphe + Task 2 commits column pointe vers `5017bb6` au lieu d'un hash dédié.
