- **Ordre strict** : (1) dédoublonnage référentiels orgs→persons (`dedupe.ts`) AVEC garde-fous §3.2 ; (2) rejeu SmartOF identité/descriptif + sessions/inscriptions ; (3) `sync-smartof-prices` hors-AGEFICE ; (4) passe Tréso AGEFICE (prix réel + 4 booléens + backfill formateur).

- **Clé Tréso à dégradation explicite (§4)** : `dates ±2j + org commanditaire + nb stagiaires` → si nb stagiaires vide/divergent, dégrader à `dates + org` → montant en départageur SEULEMENT → no-match explicite vers reliquat, JAMAIS silencieux. Le montant n'est jamais un critère d'entrée.
- **Bug prix CONFIRMÉ présent** (pas corrigé) : `336€` ×52 chez AGEFICE, propagé jusqu'à `TrainingProduct.priceHT`. La correction prix est un chantier **majeur** de E2.
- **Conflit descendant booléens** (base `true` / Tréso `false`) → reliquat E3, pas d'arbitrage auto (§2).
- **Protocole `--apply`** : chaque étape = dry-run → revue diff → `pg_dump` → `--apply`. JAMAIS deux `--apply` enchaînés sans relire la sortie. `pg_dump` avant CHAQUE `--apply`.

Écart inexpliqué **SYMÉTRIQUE** : ligne Tréso sans SP ET SP AGEFICE sans ligne Tréso (= session fantôme). Deux niveaux : global + ligne à ligne.
