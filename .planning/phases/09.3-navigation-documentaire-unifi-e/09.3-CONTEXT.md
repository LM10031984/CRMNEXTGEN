## Problème (prouvé par le code)

Les rattachements logiques sont corrects (chaîne Qualiopi), mais la **navigation** manque
et les preuves sont **éclatées sur 5 tables** :
- `Document` (FK réelles : `sessionId?`, `participantId?` seulement ; produit/tenant/veille = chaînes `entityType`/`entityId`)
- `PedagogicalAsset` (émargement, QCM=EVALUATION_ACQUIS, analyse besoin, positionnement, satisfaction chaud/froid, déroulé closure)
- `SensitiveData.idDocumentUrl` (CNI), `Person.ribKey` (RIB), `AgeficeProfile.cfpAttestationKey` (CFP) — clés MinIO éparses
- markdown `Tenant` (CGV/RI)

Conséquence : « tous les docs de l'apprenant X » est **impossible** en une requête aujourd'hui.

Click-depth actuel : depuis fiche apprenant, docs session/produit/tenant = INACCESSIBLE ;
depuis fiche produit, docs participant = INACCESSIBLE.

## Décision d'architecture (actée Laurent 2026-06-10, Option 1)

**Résolveur LECTURE pur** `resolveDocs` qui fait l'UNION des 5 sources → liste `UnifiedDoc[]`.
Zéro migration, zéro backfill, réversible. Branché sur 3 surfaces.

**Rejeté** : dénormaliser `Document` (+productId/+personId) + backfill (Option 2 advisor).
Raison : insuffisant (la moitié des preuves ne sont pas des `Document`) ET risqué à 3 sem de l'audit.
→ Reporté ROADMAP post-03/07 ; le résolveur la prépare sans la bloquer.

## Contrat figé — `UnifiedDoc`

Fonction PURE (convention projet : 97/99 tests sont des fonctions pures, pas d'intégration DB).
Fichier cible : `apps/web/src/lib/docs/resolve-docs.ts`.

```ts
export type DocSourceTable =
  | 'Document' | 'PedagogicalAsset'
  | 'SensitiveData' /*CNI*/ | 'Person' /*RIB*/ | 'AgeficeProfile' /*CFP*/
  | 'Tenant' /*CGV/RI*/;

export interface UnifiedDoc {
  sourceTable: DocSourceTable;   // D-#2 : réf polymorphe (T7-ready)
  sourceId: string;
  docType: string;
  qualiopiIndicator: string | null;  // D-#1 : conformité, pas juste existence
  anchor:
    | { level: 'participant'; participantId: string; personId: string; sessionId: string }
    | { level: 'session'; sessionId: string }
    | { level: 'product'; productId: string }
    | { level: 'tenant'; tenantId: string };
  generatedAt: Date | null;
  href: string | null;           // null = preuve à produire
  status: 'present' | 'stub' | 'missing';
  usedStub: boolean;             // D-#1 : stub = pire qu'absent (blocker T4)
}

export function resolveDocs(input: {
  documents; pedagogicalAssets; identity; legal; opcoSubmissions?
}): UnifiedDoc[]
```

Règle `usedStub` (tracée code) : `PedagogicalAsset.rawJson.source === 'stub'`. `false` pour les
docs basés sur `Document` (convention/convocation/certificat/attestation/AGEFICE/programme =
templates déterministes, jamais stub).

Wrappers Prisma minces (scope `tenantId` obligatoire) : `getDocsForPerson` / `getDocsForSession` /
`getDocsForProduct` → fetch les 5 sources puis appellent `resolveDocs`.
