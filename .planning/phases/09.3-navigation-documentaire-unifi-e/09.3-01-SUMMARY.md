# Phase 9.3 Plan 01 : Résolveur documentaire unifié (resolveDocs) Summary

`resolveDocs` — fonction PURE qui UNIONise les 6 sources de preuves Qualiopi éclatées (Document, PedagogicalAsset, SensitiveData/CNI, Person/RIB, AgeficeProfile/CFP, Tenant/CGV-RI) en `UnifiedDoc[]` normalisé, plus 3 wrappers Prisma scopés tenantId, validés par test comportemental 6-sources (mutation rouge→vert prouvée).

## What Was Built

- **`resolve-docs.ts` (fonction pure, 0 import package DB)** : contrat `UnifiedDoc` + `DocSourceTable` + `DocAnchor` recopiés verbatim depuis CONTEXT.md. Mappe chacune des 6 sources vers un `UnifiedDoc` polymorphe (`sourceTable`+`sourceId`, T7-ready). Row-types minces locaux (`DocumentRow`/`PedAssetRow`/`IdentityRow`) pour rester testable sans DB.
- **`get-docs-for.ts` (wrappers Prisma)** : `getDocsForPerson` / `getDocsForSession` / `getDocsForProduct`. Chaque source racine portant `tenantId` le scope dans son `where` (defense-in-depth). PII (CNI/RIB/CFP) lues en RELATIONS d'une racine `Person` déjà scopée `findFirst({ id: personId, tenantId })` → 0 fuite RGPD cross-tenant.
- **`resolve-docs.test.ts`** : 15 tests, dont le test central `toHaveLength(6)` (D-09.3-04) + régressions union (`toHaveLength(5)` ×3, retrait Document/CFP/Tenant) + AgeficeProfile/CFP exercée explicitement (Test 4b/6b).

## Règles de conformité implémentées

- **`usedStub`** : `true` uniquement quand `PedagogicalAsset.rawJson.source === 'stub'` (tracé renderer.ts:155). `false` pour tous les docs `Document` (templates déterministes). Status PedagogicalAsset : `stub` si usedStub, sinon `present` (pdfUrl) ou `missing`.
- **`anchor`** : `participant`/`session`/`product`/`tenant` dérivé de `Document.entityType` (seules sessionId/participantId sont de vraies FK ; product/tenant = chaînes entityId).
- **`href`** : pdfUrl pour Document/PedagogicalAsset ; clé MinIO pour CNI/RIB/CFP ; `null` pour CGV/RI (preuve markdown à rendre, pas un PDF stocké).
