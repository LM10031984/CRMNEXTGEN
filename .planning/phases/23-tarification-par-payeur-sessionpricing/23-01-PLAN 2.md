# 23-01 — Modèle SessionPricing et cascade par payeur

## Pourquoi ce plan existe

`TrainingSession.pricePerLearner` est un champ unique là où il faut une grille : une
agence au forfait et un auto-entrepreneur au tarif par personne coexistent dans la même
salle. Ce plan pose la table et fait descendre la cascade dans la source unique, sans
toucher une seule ligne existante.

## Décisions verrouillées (ne pas rediscuter)

- `amountHT` est **nullable** : une ligne créée automatiquement à l'inscription d'un
  premier salarié existe avant que le montant ne soit négocié. `NULL` = « à saisir »,
  et c'est ce qui bloquera la convention (plan 23-03). C'est la seule lecture qui rend
  compatibles « ligne auto-créée », « montant manquant signalé » et « jamais 0 en repli ».
- `mode` est **explicite**, jamais déduit du payeur. `payer-rule.ts` sert à *proposer* le
  mode à la création de la ligne, pas à le recalculer à la lecture.
- La migration est **additive et vide** : aucune ligne rétroactive.

- [ ] **2. Implémenter la sélection**

```ts
// apps/web/src/lib/pricing/session-pricing-lookup.ts
/**
 * Sélection PURE de la ligne tarifaire applicable à un payeur.
 * Priorité : sa propre ligne, sinon la ligne par défaut de la session
 * (`sponsorOrgId = null`), sinon rien — jamais un montant inventé.
 */
export interface SessionPricingLine {
  sponsorOrgId: string | null;
  mode: 'FORFAIT_GROUPE' | 'PAR_STAGIAIRE';
  amountHT: number | null;
}

export function pickPricingLine(
  lignes: SessionPricingLine[],
  sponsorOrgId: string | null,
): SessionPricingLine | null {
  if (sponsorOrgId) {
    const sienne = lignes.find((l) => l.sponsorOrgId === sponsorOrgId);
    if (sienne) return sienne;
  }
  return lignes.find((l) => l.sponsorOrgId === null) ?? null;
}
```

- [ ] **6. Schéma Prisma**

Dans `packages/db/prisma/schema.prisma` :

```prisma
enum SessionPricingMode {
  FORFAIT_GROUPE
  PAR_STAGIAIRE
}

/// Le prix appartient au couple (session × payeur), pas à la session.
/// `sponsorOrgId = null` : ligne par défaut « indépendants / TNS ».
/// `amountHT = null` : ligne créée, montant pas encore négocié — bloque la convention.
model SessionPricing {
  id           String             @id @default(uuid())
  tenantId     String
  sessionId    String
  session      TrainingSession    @relation(fields: [sessionId], references: [id], onDelete: Cascade)
  sponsorOrgId String?
  sponsorOrg   Organization?      @relation(fields: [sponsorOrgId], references: [id])
  mode         SessionPricingMode
  amountHT     Decimal?           @db.Decimal(10, 2)
  vatRate      Decimal            @default(0) @db.Decimal(5, 2)
  note         String?
  createdAt    DateTime           @default(now())
  updatedAt    DateTime           @updatedAt

  @@unique([sessionId, sponsorOrgId])
  @@index([tenantId, sessionId])
}
```
