# 23-02 — Quotes-parts et verrou collectif

## Pourquoi ce plan existe

Un forfait ne se recopie pas sur chaque inscrit, il se répartit. Et cette répartition
devient interdite dès qu'un seul membre du groupe est engagé — c'est le seul endroit du
produit où un verrou individuel a une conséquence collective, et le piège principal de
tout le sujet.

## Décisions verrouillées

- Reliquat d'arrondi sur le **dernier** inscrit (ordre `createdAt`).
- Le forfait est **ferme** : 4 annoncés, 3 présents ⇒ forfait entier dû.
- Verrous : `classifyParticipantPrice`, **jamais** réimplémentés.
- L'outil expose deux issues et **n'en choisit aucune**.

```ts
import { describe, it, expect } from 'vitest';
import { distributeGroupShares } from '../group-shares';

describe('distributeGroupShares', () => {
  it('4 500 € sur 11 inscrits : reliquat sur le DERNIER (cas SES-0106)', () => {
    const r = distributeGroupShares(450000, ['a','b','c','d','e','f','g','h','i','j','k']);
    expect(r.slice(0, 10).every((p) => p.shareCentimes === 40909)).toBe(true);

    expect(r.reduce((s, p) => s + p.shareCentimes, 0)).toBe(450000);
  });

  it('la somme retombe exactement sur le forfait, quel que soit l’effectif', () => {
    for (const n of [1, 2, 3, 6, 7, 9, 11, 13, 25]) {
      const ids = Array.from({ length: n }, (_, i) => `p${i}`);
      for (const forfait of [250000, 450000, 160800, 1]) {
        const total = distributeGroupShares(forfait, ids).reduce((s, p) => s + p.shareCentimes, 0);
        expect(total).toBe(forfait);
      }
    }
  });

  it('un seul inscrit porte le forfait entier', () => {
    expect(distributeGroupShares(450000, ['seul'])).toEqual([{ participantId: 'seul', shareCentimes: 450000 }]);
  });

  it('aucun inscrit : aucune écriture, et surtout pas une division par zéro', () => {
    expect(distributeGroupShares(450000, [])).toEqual([]);
  });

  it('ajout puis retrait : la somme reste exacte et le forfait n’a pas bougé', () => {
    const avant = distributeGroupShares(250000, ['a','b','c']);
    const apres = distributeGroupShares(250000, ['a','b','c','d']);
    const retour = distributeGroupShares(250000, ['a','b','c']);
    for (const r of [avant, apres, retour]) {
      expect(r.reduce((s, p) => s + p.shareCentimes, 0)).toBe(250000);
    }
    expect(retour).toEqual(avant);
  });

  it('refuse un forfait négatif', () => {
    expect(() => distributeGroupShares(-1, ['a'])).toThrow(/forfait/i);
  });
});
```
