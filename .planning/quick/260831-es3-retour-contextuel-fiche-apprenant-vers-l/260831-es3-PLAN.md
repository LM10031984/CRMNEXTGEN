# Quick 260831-es3 — Retour contextuel depuis la fiche apprenant

**Date :** 2026-08-31
**Demande (Laurent) :** « quand je rentre sur une session de formation et que je veux consulter un apprenant pour avoir son téléphone, quand je fais retour je ne reviens pas sur la session mais sur la liste de tous les apprenants. »

## Cause

`components/ui/back-to-list-link.tsx` lit `document.referrer` et ne l'exploite **que** si son chemin est exactement `fallbackHref` (la liste). Depuis `/app/sessions/<id>`, le test échoue → retour sur `/app/apprenants`.
Le referrer est en plus non fiable en App Router : il n'est pas mis à jour par les navigations client (`<Link>`), il reste celui du dernier chargement complet du document.

## Approche

Paramètre `?from=<chemin interne>` explicite sur les liens entrants, lu par la page de destination. Fiable au rafraîchissement, en navigation client et en ouverture dans un nouvel onglet. Le mécanisme referrer existant est conservé comme repli.

## Tâches

1. **`src/lib/nav/from-link.ts`** (module neutre, sans `'use client'` — convention repo)
   - `withFrom(href, from)` : ajoute `from` en query en préservant les query params existants.
   - `parseFrom(raw)` : n'accepte qu'un chemin interne commençant par `/app/` (rejette `http…`, `//evil`, `\`, chemins hors `/app/`) → anti open-redirect.
   - `labelForFrom(from)` : libellé métier (« Retour à la session », « Retour à l'organisation », …).
2. **`components/ui/back-to-list-link.tsx`** : prop optionnelle `from`. Si valide → href + label contextuels ; sinon comportement actuel inchangé.
3. **`app/app/apprenants/[id]/page.tsx`** : lire `searchParams.from`, le passer au bouton retour.
4. **Liens entrants** — clients via `usePathname()`, serveurs via chemin littéral :
   - `components/sessions/session-participants-list.tsx` (cas signalé)
   - `components/sessions/qualiopi-matrix/matrix-row.tsx` (cas signalé)
   - `components/apprenants/learner-quick-view-button.tsx`
   - `app/app/organisations/[id]/page.tsx`, `app/app/factures/[id]/page.tsx`
   - `components/produits/tabs/product-learners-tab.tsx`, `product-docs-tab.tsx`
   - `app/app/budget-agefice/page.tsx`, `app/app/inscriptions/[id]/page.tsx`
5. **Tests** Vitest sur le helper pur (dont les cas d'open-redirect).
6. **Gates** : `tsc --noEmit` + vitest ciblé.

## Hors périmètre

Les 5 autres fiches de détail (devis, produits, formateurs, sessions, organisations) gagnent le mécanisme mais leurs liens entrants ne sont pas tous annotés — à faire au fil de l'eau.
