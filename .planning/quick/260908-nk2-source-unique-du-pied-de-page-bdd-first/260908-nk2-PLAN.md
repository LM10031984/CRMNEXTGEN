# Quick 260908-nk2 — Une seule source pour le pied de page des documents

**Date :** 2026-09-08
**Branche :** `quick/260908-footer-source-unique` (worktree `files-lieu`, partie de `main` @ `f96db72`)
**Demande (Laurent) :** « oui fais-le et pousse en prod », après que le risque a été signalé.

## Le risque qu'on ferme

Le pied de page n'avait pas une source unique :

| Documents | Fonction | Source |
|---|---|---|
| Certificats, attestations, émargements (pack closure) | `renderCorpFooter(of)` | **base d'abord** |
| **Conventions, programmes, convocations, docs légaux, veille** | `renderOfPagedFooter()` | **environnement SEUL** |

Conséquence concrète : l'écran Paramètres n'atteignait pas le second groupe. Une même convention
pouvait donc afficher **deux SIRET différents** — celui de la base dans le corps, celui de
l'environnement en pied de page. Et la valeur posée sur Vercel n'étant pas relisible en ligne de
commande (comportement connu, [[feedback-vercel-env-cli-sensible]]), on ne pouvait pas prouver
qu'elle était juste.

## Ce qui a rendu le correctif minime

Les cinq gabarits recevaient **déjà** un `of: OfConfig` chargé par `loadOfConfig(tenantId)` — ils
oubliaient simplement de le passer au pied de page. Le correctif tient donc en un paramètre.

- `renderOfPagedFooter(of?: OfConfig)` — la config passée gagne, `getOfConfig()` (environnement)
  reste le repli pour tout appelant non migré.
- Les cinq appels passent `of` (la veille reçoit un `VeilleTenantSnapshot`, on lui a ajouté un
  troisième paramètre optionnel, alimenté par `veille-export.ts` qui charge déjà la config).

## Vérification

- 3 tests neufs (`of-paged-footer.test.ts`) avec l'environnement **volontairement périmé** dans le
  mock : ils échouent si le code retombe dessus.
- **Test de puissance joué** : en remettant `const cfg = getOfConfig()`, 2 des 3 tests virent au
  rouge ; restauré, 3/3 verts.
- Preuve de bout en bout sur la vraie base, en simulant une variable d'environnement périmée :
  `avec la base → SIRET : 95131909400029` / `sans la base → SIRET : 95131909400011`.
- 1867 tests verts, `tsc` 0, `eslint` 0.

## Effet de bord bienvenu

Le nom affiché suit lui aussi la base : « Start Academy » (saisi dans Paramètres) au lieu de
« START ACADEMY » (variable d'environnement en capitales).
